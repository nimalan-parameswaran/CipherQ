# CipherQ

**CipherQ - Your Private Cloud. Your Personal AI.**

CipherQ is an open-source private cloud powered by the Arduino UNO Q and Gemma, designed to let users store, search, and interact with their files using local AI. It aims to provide secure document storage, AI-powered question answering, and intelligent file retrieval while keeping personal data under the user's control. The goal is to make private AI accessible to students, freelancers, and small businesses.
