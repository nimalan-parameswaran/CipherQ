🔒 Authenticated Encryption

Every file is encrypted with a random 256-bit Data Encryption Key (DEK) wrapped under a server Master Key using vetted streaming AEAD.

🧠 On-Demand Local AI

Semantic document retrieval and Q&A run strictly on local hardware. Zero document contents are ever transmitted to external AI APIs.

⚡ Engineered for 4GB RAM

Optimized for Arduino UNO Q (Debian Linux). Streaming I/O caps transfer memory to under 1MB; intelligent guards prevent OOM crashes.

🛡️ Transparent Security Disclosures

CipherQ is a server-managed encrypted vault, not an end-to-end encrypted (E2EE) zero-knowledge platform. Because local AI processing and downloads require in-memory decryption, the server holds the Master Key. We do not make false claims of zero-knowledge or absolute forensic memory wiping.
