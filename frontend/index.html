Security, without shortcuts

Privacy, explained honestly.

CipherQ uses server-managed encryption and local AI processing. The server holds the master key and decrypts authorized content in memory when required.

CipherQ is not an end-to-end encrypted or zero-knowledge service. This boundary is necessary for authorized downloads, indexing, and local retrieval. Read the complete threat model and security disclosures.
